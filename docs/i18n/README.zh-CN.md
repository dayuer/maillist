**Nibwire** 是一个开源、自托管的 newsletter（邮件订阅）与邮件列表引擎。整个程序只有一个 Go 二进制文件，订阅者、每期内容、投递记录与统计数据都放在同一个 SQLite 文件里。你可以用命令行操作它，也可以让 AI 助手通过 **MCP（Model Context Protocol）** 代你操作。助手被限制在一组护栏之内，任何提示词都绕不过去。

不需要照看后台面板，也不需要运维数据库集群、缓存或消息队列。名单、数据和服务器都在你自己手里。

- 🤖 **为 AI 助手而生**：27 个 MCP 工具、按权限划分的凭据、每日额度与完整的审计日志
- 📦 **一个程序，一个文件**：整份 newsletter 都在一个数据库里，一条命令即可备份
- 🛡️ **安全由设计保证**：不会重复发信，不会重发已发出的一期，也不会给已退订的人发信
- ⚡ **又快又守规矩**：并发投递，自动按邮件服务商的限额调节速度
- 💸 **运行成本低**：最便宜的 VPS 就能轻松运行
- 📬 **读者该有的都有**：一键退订、双重确认订阅、公开归档、自定义域名
- 🔓 **开源**：AGPL-3.0，另提供商业授权

## 为什么选择 Nibwire？

**为 AI 助手设计，不只为人设计**<br>
大多数 newsletter 工具默认有一个人在后台点来点去。Nibwire 假设你可能希望由助手来写草稿、做检查、发测试信、安排发送并读回报告，每一步都是一个 MCP 工具。所有危险操作都是从结构上做不到，而不只是"不建议"：没有删除工具，无法跳过发送前检查，也无法超出你给这个凭据设定的额度。

**运维极其简单**<br>
一个进程包办一切：归档页、打开与点击统计、定时、发送、退信处理。所有数据都在一个 SQLite 文件里。升级就是拉一个新镜像，备份就是 `nibwire db backup`，半夜不会有别的服务需要你去救。

**五条始终成立的保证**
1. 永远不会给已退订、退信或投诉过的地址发信。
2. 没有通过发送前检查的一期发不出去。
3. 已经发出的一期不能再发一次。
4. 每天的发送量不会超过额度，即使今天暂停、明天恢复也一样。
5. 即使服务器在发送途中崩溃，读者也不会收到重复的邮件。

**快，而且守规矩**<br>
并发发送，并自动按邮件服务商当前允许的速度调节：被要求放慢时自动降速，之后再逐步回升。压测中 20,000 封邮件约 45 秒发完，零重复、零失败。如果某次发送超出当天剩余额度，会在开始前直接拒绝，而不是发到一半卡住。

**名单默认保持健康**<br>
退信和投诉会自动加入屏蔽名单，并在所有 newsletter 之间共享。退信率或投诉率超过安全阈值时，发送会自动暂停。可选的名单清理功能会先给长期不活跃的读者发一封"最后的机会"邮件，再将其移出，从而保护发件信誉和打开率。

**读者体验完整**<br>
一键退订（RFC 8058）、可选的双重确认与欢迎信、公开订阅表单，以及带每期页面、作者页和 sitemap 的公开归档，归档也可以放在独立域名上。打开与点击统计会过滤掉安全网关的自动扫描，数据才真实可信。

**按你习惯的方式写作**<br>
每期内容可以用 Markdown（支持提示框）或完整的 HTML 编写。Nibwire 会自动生成纯文本版本、收件箱预览文字和适配手机的版式；如果邮件长到会被 Gmail 截断（连退订链接一起被隐藏），会在发送前拦下。

**带着名单无缝迁移**<br>
通过 CSV 从其他平台导入订阅者，保留状态和互动历史，最活跃的读者仍然最先收到新一期。

## 快速体验

在自己电脑上几分钟就能跑完整流程。它使用内置的本地邮件接收端，不需要任何账号或密钥，邮件也不会离开你的电脑。

```bash
git clone https://github.com/dayuer/nibwire.git
cd nibwire
KEEP=1 scripts/compose-smoke.sh
```

脚本会构建镜像、启动 Nibwire，然后模拟一位读者走完全程：创建 newsletter、发出一期、读者打开、点击链接、一键退订，报告记录下每一步。加上 `KEEP=1` 后环境会保留，方便你继续探索。
